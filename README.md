# AudioFlow 🎵
A high-performance music streaming and downloading software tool built with **FastAPI** and **Vanilla JS**.

## Features
* **Zero-Latency Streaming**: Instant preview of audio files via FastAPI StreamingResponse.
* **Smart Download**: Secure proxy downloading with forced headers.
* **Glassmorphism UI**: Modern, responsive interface using CSS backdrop filters.

## Tech Stack
* **Backend**: Python 3.10+, FastAPI, HTTPX
* **Frontend**: HTML5, CSS3, JavaScript (ES6)
* **Icons**: Phosphor Icons

## Setup
1. `pip install -r requirements.txt`
2. `uvicorn main:app --reload`
